# SchoolKingdoms — демо-версія (1 клас)

Публічна демо-версія для портфоліо: усе для 1 класу без реєстрації та бази даних.

**Є:** тренажери 1 класу (`klas-1/`, `learn/`), тести 1 класу (плеєр `test.html`), ігри (`games/`).
**Немає:** входу й реєстрації, Героя та характеристик, монет і нагород, Арени, інвентарю,
кабінету батьків, адмінки, Firebase. Прогрес зберігається лише в `localStorage` браузера.

## Збірка

```bash
node tools/build-demo.mjs          # → dist-demo/
node tools/demo-smoke.mjs          # smoke-тест у Chromium (потрібен playwright)
```

Що робить `build-demo.mjs`:
- копіює сторінки 1 класу, ігри, плеєр тестів і лише ті картинки/звуки, на які вони посилаються;
- підміняє `firebase-config.js` на `demo/sk-demo.js` (той самий `window.SK`, але без бази);
- підміняє нагороди, 🐞-звіти й прогрес Героя заглушками з `demo/stubs/`;
- прибирає «Арену» з футера й меню, підказки «Увійди як Герой» і нарахування характеристик;
- сторінки повної версії (hero, arena, login, parent…) стають редіректом на демо-головну;
- падає, якщо в демо лишилось звернення до Firebase чи посилання на Арену.

## Тести

`data/tests.json` збирається з `test-template-levels.json`, `test-sklad-chysla-visual.json`
і, якщо є, з **`demo/data/tests-export.json`** — експорту з адмінки
(Адмінка → Навчання → експорт JSON). У демо потрапляють лише активні тести 1 класу.

## Що знайшов smoke-тест у повній версії

- `klas-1/slovnykovi-slova.html` посилається на картинки, яких немає в репозиторії:
  `img/sl/dzob.webp`, `img/sl/zozulia.webp`, `img/sl/zahadka.webp`.
- `learn/learn_kompyuter.html` шукає необовʼязкову озвучку `audio/infcomp_N.mp3` (файлів ще немає).
