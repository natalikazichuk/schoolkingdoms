# 🏰 SchoolKingdoms — демо (1 клас)

**Гейміфікована освітня платформа для дошкільнят і школярів** — українською мовою.

Це публічна демо-версія для портфоліо: тренажери, тести та ігри для 1 класу,
без реєстрації й бази даних. Прогрес зберігається лише в браузері.

- 🎮 **Демо:** https://natalikazichuk.github.io/schoolkingdoms-demo/
- 🎬 **Презентація:** https://natalikazichuk.github.io/schoolkingdoms-demo/prezentaciya.html
- 🌐 **Повна версія:** https://school-king.pp.ua

Повний код платформи (вхід, Герой, Арена, кабінет батьків, адмінка, сервер) — у приватному репозиторії.
Цей репозиторій збирається автоматично, правки сюди напряму не вносяться.
