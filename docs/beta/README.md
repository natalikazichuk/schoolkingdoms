# Бета-тестування SchoolKingdoms

Гілка `beta` — бета-версія сайту з анкетою для тестувальників.
Адреса: **https://beta.school-king.pp.ua**. Тест триває тиждень.

## Як це працює

```
тестувальник ── beta.school-king.pp.ua ──▶ nginx (/srv/sk/beta, гілка beta)
     │                                      └─ /api/ → той самий API і база, що й основний сайт
     ├─ 🐞 помилка  → адмінка (як і раніше, sk-report.js)
     └─ 📝 анкета   → Google Apps Script → Google Таблиця «SchoolKingdoms — бета-тестування (відповіді)»
```

- `sk-beta.js` — кнопка «📝 Анкета» зліва знизу на кожній сторінці. Вмикається лише на
  домені `beta.…` (для перевірки деінде — відкрити сторінку з `?beta=1`, вимкнути — `?beta=0`).
- Відповіді зберігаються в браузері після кожної зміни, тож анкету можна заповнювати
  частинами протягом тижня. На 7-й день кнопка блимає: «Час надіслати анкету!».
- Пристрій, ОС, браузер, екран, Герой, дні тестування й відвідані сторінки
  додаються в рядок автоматично.
- Після надсилання відповіді лишаються; можна змінити й надіслати ще раз
  (у таблиці — новий рядок з «Надсилання № 2»).
- Акаунти й прогрес спільні з основним сайтом: тестувальники грають своїми Героями.

## Налаштування (один раз)

### 1. Таблиця й Apps Script

1. Відкрити таблицю «SchoolKingdoms — бета-тестування (відповіді)» у Google Drive.
2. **Розширення → Apps Script**. Видалити весь код і вставити [`apps-script.gs`](apps-script.gs). Зберегти (💾).
3. Якщо хочеться лист на пошту про кожну анкету — вписати адресу в `NOTIFY_EMAIL`.
4. **Розгорнути → Нове розгортання** → тип ⚙️ **Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі**
5. Дозволити доступ (Google попередить «неперевірений застосунок» → «Додатково» → «Перейти»).
6. Скопіювати **URL веб-застосунку** (`https://script.google.com/macros/s/…/exec`).
   Перевірка: відкрити його в браузері — має бути `{"ok":true,"hello":"SchoolKingdoms beta"}`.
7. Вставити URL у `sk-beta.js` → `var SHEET_URL = … || 'URL';`, підняти `?v=` (`node tools/bump-version.mjs sk-beta.js`), закомітити в `beta`.

Змінили код Apps Script → **Розгорнути → Керування розгортаннями → ✏️ → Версія: нова**
(тоді URL лишається той самий).

### 2. Домен

1. DNS: запис для `beta.school-king.pp.ua` — такий самий, як для `school-king.pp.ua`
   (A на ту саму IP або CNAME на `school-king.pp.ua`).
2. Домашній проксі: додати `beta.school-king.pp.ua` (сертифікат HTTPS) і пересилати
   на ту саму VM :80 **з тим самим заголовком Host** (`beta.school-king.pp.ua`) —
   за ним nginx вибирає папку, а API перевіряє, що запит прийшов зі свого домену.

### 3. Сервер

```sh
sudo git clone -q -b beta https://github.com/natalikazichuk/schoolkingdoms.git /srv/sk/beta
sudo /srv/sk/beta/server/beta-deploy.sh
```

Далі cron кожні 2 хв сам підтягує нові коміти з `beta` (`/var/log/sk-beta-deploy.log`).
Основний сайт не змінюється. Вимкнути бету: `sudo /srv/sk/beta/server/beta-deploy.sh --off`.

⚠ API в беті — основний (з `main`). Зміни в `server/app/` у гілці `beta` на сервері не запрацюють.

## Запуск тесту

1. Розіслати тестувальникам посилання https://beta.school-king.pp.ua і термін (7 днів).
2. Попросити: за тиждень спробувати 5 завдань з анкети, помилки одразу слати 🐞,
   анкету заповнювати поступово й надіслати наприкінці.
3. Відповіді — у таблиці, помилки — в адмінці «Звіти».

Шаблон анкети для друку/обговорення — документ «Анкета бета-тестувальника».
