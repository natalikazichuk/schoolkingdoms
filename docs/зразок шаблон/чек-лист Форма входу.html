Клік по значку пріоритету чи серйозності відкриває вибір; зміна застосовується лише після «Підтвердити» (змінені значки обведені синім). Клік по заголовку розділу (або Enter) згортає / розгортає його.
Прогрес зберігається на цьому пристрої (localStorage).
Як адаптувати шаблон: змініть масив DATA у кінці файлу (мінімальна довжина пароля, тексти помилок, адреси сторінок).
Тестові дані — значення для полів форми; кнопка «Копіювати» кладе значення в буфер обміну. Біля кожного — ID перевірки з чек-листа.
Скрипти для консолі — відкрийте сторінку форми входу продукту, що тестується, натисніть F12 → Console, вставте скрипт і натисніть Enter. Скрипти працюють саме на сторінці продукту, а не на цій сторінці. Якщо поле не знайдено — змініть селектор на початку скрипту.
⚠ Скрипти 10 і 11 (XSS і перебір паролів) запускайте лише на тестовому середовищі свого продукту.
