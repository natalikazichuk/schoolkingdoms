# Прискорити «🪄 Одягти» (генерація образу понад 10 хв)

Стан: план, ще не почато. Записано 2026-10-28.

## Як працює зараз

Герой тисне «🪄 Одягти» → сервер ставить набір у чергу (`server/app/src/avatar.js`) →
воркер на ПК з ComfyUI забирає завдання, малює **дві пози поспіль** (пряма з `baseImage`,
потім бойова з `fightImage`) і віддає обидві разом у `/api/avatar/worker/result`
(протокол — `server/AVATAR-WORKER.md`). Дитина бачить образ лише після обох поз.

## Де губиться час

- **Модель.** Qwen Image Edit (~20 млрд параметрів). Не вміщується у відеопам'ять —
  частина ганяється через ОЗП, і одна картинка займає 5–10 хв замість ~1.
- **Кроки.** Звичайний workflow — 20–40 кроків на картинку.
- **Розмір полотна.** База приходить із прозорим запасом з боків і зверху (для довгої
  зброї), тож пікселів більше, ніж треба.
- **Дві генерації поспіль**, і результат — тільки після обох.
- **ПК заснув / воркер не запущений** — завдання просто стоїть у черзі.

## План

### 1. Виміряти — сайт (½ дня)
- [ ] Для кожного завдання писати час етапів: поставлено → взято воркером → пряма поза →
      бойова поза → файли збережено.
- [ ] В адмінці: середній час за етапами і чи воркер онлайн (останній claim/heartbeat).

### 2. Прискорити ComfyUI — ПК з воркером (найбільший виграш)
- [ ] Lightning LoRA для Qwen Image Edit: 4–8 кроків замість 20–40 (≈ у 4–6 разів швидше).
- [ ] FP8 або GGUF-версія моделі, щоб повністю вміщувалась у відеокарту.
- [ ] Малювати на ~1 Мпікс (напр. 832×1216), далі збільшувати.
- [ ] Не вивантажувати модель між прямою і бойовою позою.
- [ ] Вимкнути сон ПК, воркер — в автозапуск.
- Потрібно знати: модель відеокарти й обсяг її пам'яті; де лежить скрипт воркера (у репо його немає).

### 3. Перша картинка раніше — сайт + воркер (1 день)
- [ ] Воркер відправляє пряму позу одразу, сайт ставить її аватаром.
- [ ] Бойова поза домальовується у фоні й дописується в той самий образ
      (новий виклик або поле в `result`, сумісне зі старим воркером).

### 4. Чесний статус для дитини (½ дня)
- [ ] «Малюю… 1 з 2».
- [ ] Воркер не на зв'язку → «Художник відпочиває, образ з'явиться пізніше».

### 5. Кеш популярних наборів
- [ ] Уночі, коли ПК вільний, прогнати стартові комплекти для 14 нових шаблонів
      (8 джур + 6 малюків) — вони видаватимуться миттєво (кеш за `key` уже є).

## Очікуваний результат

Після кроків 2 і 3 — перша картинка за 1–2 хв замість 10+; популярні набори з кешу — за секунди.
