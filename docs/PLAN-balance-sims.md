# План: симуляції боїв для балансу класів

Домовились 25.10.2026. **Запускаємо, коли всі вміння класів готові до бою** (поки що рано:
частини вмінь немає, і статистика брехатиме).

|---|---|---|

- перевірити наживо ще не перевірені вміння (позначка «🔎 не перевірено» в адмінці).

## 1. Що ганяємо

Сітка сценаріїв — кожна клітинка = **500–1000 боїв** (різні зерна випадковості):

- **Рівні:** 10 · 20 · 30.
- **Прокачка вмінь:** повна (усі доступні на рівні вміння на 100%) і половинна (усі на 50%).
  Додатково: «реальна» — набір і відсотки, як у живих героїв (з бази), коли їх буде досить.
- **Пари класів:** кожен з кожним, включно з дзеркалами (Лицар — Лицар…): 4 класи → 10 пар.
- **Речі:** однакові для обох (той самий набір із каталогу за рівнем) — щоб міряти саме класи;
  окремо — «типовий» набір класу (Лицар зі щитом, Слідопит з кинджалом / луком / кнутом).
- **Розум бійців:** обидва — один і той самий «розумний» вибір вмінь (як бот 100%), без людських помилок;
  окремо — «навмання» (як слабкий бот), щоб бачити, наскільки клас тримається на правильній грі.

## 2. Що міряємо (вихід)

Для кожної клітинки:
- **% перемог** кожного (і нічиїх), довірчий інтервал;
- **на якому ході закінчується бій** (середнє, медіана, розподіл) — головне для нашої ідеї
  «Слідопит виграє коротке, Лицар — довге»;
- **хто виграє залежно від довжини бою** (перемоги до 10 ходу / 10–20 / після 20);
- **мана / Запал:** коли закінчується, скільки ходів бій триває «на сухо»;
- **внесок вмінь:** скільки урону / лікування / скасованих ударів дало кожне вміння й перевага класу;
- **концентрація:** середній рівень по ходах (Приціл, Стійкість, «Мисливський азарт»);
- **ефекти контролю:** скільки ходів суперник був оглушений / осліплений / без зброї / без щита.

Таблиця + графіки (HTML-звіт), щоб було видно «що +/−».

## 3. Як реалізуємо (коли дійде черга)

- Окремий скрипт `tools/sim/` на Node, що використовує ті самі файли, що й гра:
  `sk-items.js`, `sk-arena-rules.js`, `sk-skills.js`, `sk-battle.js` (як `server/app/test/*`),
  без браузера й сервера. Бій = `SKBATTLE.create` + `turn` до кінця.
- Бійці будуються як у грі: `SKARENA.fighter` + `skillValues` на потрібному відсотку,
  переваги класу (`CLASS_PERKS`), ріст за рівень (`levelBonus`).
- Обом бійцям — однаковий «мозок» (вибір зон і вмінь), щоб порівнювати класи, а не розум.
- Результати — JSON + HTML-звіт (графіки). Звіт можна опублікувати як сторінку.

## 4. Цикл балансування

1. Прогнати сітку → звіт.
2. Знайти перекоси (клас виграє > 60% у парі на рівному рівні й речах; бої занадто довгі / короткі;
   вміння, що майже нічого не дає, чи навпаки вирішує бій саме).
3. Змінити числа (`RULES` у `sk-skills.js`, `CLASS_PERKS` / `LEVEL_BONUS` у `sk-arena-rules.js`) — по одній зміні.
4. Прогнати знову, порівняти з попереднім звітом. Записати, що змінили і чому.

## 5. Що вже помітили в живих логах (кандидати на перевірку симуляцією)

- Слідопит із сильними речами (541 Запалу) майже не «видихається» — ціни перемикачів / запас.
- «Змастити зброю отрутою» на низькій майстерності дає мало (+1 урону, отруєння рідко).
- «Пісок в очі» проти Лицаря зі Стійкістю часто «відвернувся», а Запал знято.
- «Перев'язка» слабка (5% за 15 Запалу) — так задумано, перевірити, чи не марна.
- Сильний бот-Лицар (400 мани) тримає Благословення + Кам'яну шкіру майже весь бій;
  Обеззброєння кожні 5 ходів дуже болісне для Слідопита з одною зброєю.
- Концентрація Слідопита без «Мисливського азарту» майже не росте (бот влучає ~75%).
- Слідопит 26.10: до 4–6 ударів за хід (речі «дод. атака» + Друга/Третя атака + лівою + Поспіх) — Поспіх послаблено (−40, з другою зброєю 50%); отрута лише на основному клинку; перевірити симуляцією кількість ударів і роль речей з «дод. атакою».
