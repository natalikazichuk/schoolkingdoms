🧪 Тестові дані — що створити й додати перед тестом

Усі скрипти виконуються в Console (F12) на сторінці arena.html, увійшовши як Герой (Вова). Кнопка «Копіювати» → вставити в Console → Enter. Якщо Chrome просить, спершу набери allow pasting.

1. Акаунти

  • Герой Вова — основний для всіх тестів.
  • Другий Герой (будь-який інший) — лише для M-07 / розділу B: асортимент у кожного свій.
  • Батьківський / адмін акаунт — для адмінки «Предмети» (розділ I) і перевірки «без входу Героя» (M-A01).

5. Порядок

  1. №1 резервна копія → №2 гроші → №3 тестовий набір → вдягнути Пояс піжона.
  2. Розділи A–E, H, I.
  3. Розділ F (сумка й скриня): №4 заповнити сумку → №5 нагороди в скриню → №6 скриня «згорає» за 1 хв.
  4. Після тестів: №8 прибрати заповнювачі або №9 повністю відновити з копії; в адмінці повернути 🛒 і видалити ТЕСТ-предмети.
🧭 Покроковий план перевірки

Етап 0. Підготовка (~10 хв)

  1. Адмінка (акаунт батьків): Шапка школяра IT-003 → 🛒 у рядку стає 🚫, лічильник «🚫 Не в магазині» +1 → M-I01
  2. Картка будь-якої речі → галочка «🚫 Недоступна в магазині» → «Зберегти» → F5 → галочка лишилась → M-I02 (потім зняти)
  3. Фільтр «🚫 Не в магазині» → лише позначені речі → M-I03. Створити «ТЕСТ ціна 0» і «ТЕСТ неактивний»
  4. Вийти з акаунта → arena.html: гардероб «Увійди як Герой…», плитка «Магазин» → «Магазин недоступний» → M-A01
  5. Увійти як Вова → Console: №1 → №2 → №3 → №7 (✅ → M-B05 M-B06) → F5
  6. У гардеробі вдягнути Пояс піжона

Етап 1. Доступ і бій

  1. «Почати бій» → «← Назад» → «Магазин»: «Спершу заверши бій», кнопка — «Продовжити бій» → M-A02
  2. Довести бій до кінця → магазин відкривається → M-A03
  3. Новий бій → здатися на 1-му раунді → Ctrl+F5: «Продовжити бій» немає, магазин відкривається → M-A04
  4. Магазин у вкладці 1 → у вкладці 2 «Почати бій»: «Спершу вийди з магазину…» → M-A05; закрити ✕ у вкладці 1 → у вкладці 2 бій починається → M-A06
  5. Бій у вкладці 2 → у вкладці 1 «Магазин»: «Спершу заверши бій»; після бою — знову «Почати бій» → M-A08
  6. Закрити магазин: ✕, Esc, клік повз вікно → M-A09
  7. (P3) Відкрити магазин і закрити вкладку → 2+ хв → в іншій вкладці бій починається → M-A07

Етап 2. Асортимент

  1. Вкладки «Речі (20)», «Зілля (5)», «Викуп (0)», є зілля здоровʼя → M-B01
  2. Запамʼятати 2–3 товари → закрити, F5, відкрити → той самий набір → M-B02
  3. Картка товару: іконка, назва, характеристики, ціна в зол/сріб → M-B07

Етап 3. Сумка й пояс (до продажу зілль)

  1. Біля «Речі» лічильник «N/100», вдягнене не рахується → M-F01
  2. У сумці магазину немає вдягненого (Пояса піжона) → M-F02
  3. Зілля здоровʼя ×5 → у пояс: фляжка в поясі, у сумці ×4 → M-F03; зняти → ×5 → M-F04

Етап 4. Прилавок

  1. Річ із сумки → «💰 Продаю» з +, у сумці бліда → M-C01
  2. Товар двічі → дві позиції в «🛍 Купую» → M-C02
  3. Рядок на прилавку → повернувся → M-C03; «Очистити» → порожньо → M-C04
  4. Покупок більше, ніж грошей → «не вистачає X», кнопка неактивна → M-C05; додати продаж → «Буде» = маєш + продаж − купівля → M-C06
  5. Речі на прилавку → закрити → відкрити: прилавок порожній, гроші ті самі → M-C09

Етап 5. Угода і ціни

  1. Купити 1 річ → «Укласти угоду» → Скасувати: нічого не змінилось → M-D03
  2. Те саме → Підтвердити: гроші − ціна, «Угоду укладено 🤝» → M-D01; річ біла, 100%, характеристики видно → M-D02
  3. Продати по одній і звірити «+» з таблицею тестового набору → M-D04 M-D05 M-D06 M-D07; Шапка школяра (🚫) продається за +3
  4. Купити 2 Зілля здоровʼя → стопка ×7 → M-D08
  5. Продати 2 + купити 3 однією угодою → баланс правильний → M-D09; гроші в шапці й у гардеробі → M-D10; F5 → усе збереглось → M-D11

Етап 6. Викуп

  1. Продати річ → «Викуп»: та сама ціна → M-E01; викупити → той самий бонус і міцність → M-E02
  2. Знову продати → гроші як до першого продажу → M-E03

Етап 7. Смітник і скриня

  1. Права кнопка / довге натискання → «🗑 Викинути» → у смітнику, сумка −1 → M-F06; натиснути в смітнику → повернулась → M-F07
  2. Console №4 (сумка 100/100): зняти вдягнене → «Сумка повна» → M-F05; купити зілля здоровʼя (стопка є) → дозволено → M-C08
  3. Викинути 1 річ (99/100) → 2 покупки → «101/100 — забагато речей» → M-C07
  4. Console №5 → речі в 🎁 Скрині «ще 3 д» → M-F09; викинути річ → забрати зі скрині → M-F10
  5. Console №6 → через 1 хв F5 → скриня порожня
  6. (P3) №5 ще 10 разів (30/30) і ще раз → нагороди зникають, без помилок → M-F11
  7. Console №8 → заповнювачі прибрано

Етап 8. Надійність

  1. F12 → Network → Offline → угода: «Угода не відбулась», нічого не змінилось → M-G01
  2. Річ на прилавку у вкладці 1 → у вкладці 2 продати / викинути → угода у вкладці 1: «річ уже не в сумці» → M-G02
  3. Подвійний швидкий клік «Укласти угоду» → одна угода → M-G04
  4. (з батьками) Схвалити завдання з монетами під час угоди → обидві суми на місці → M-G03
  5. Console без червоних помилок → M-G05

Етап 9. Вигляд (F12 → іконка телефона)

  1. Ширина 1400: три колонки, плитка зліва вгорі → M-H01
  2. Ширина 1000: плитка під заголовком, не налазить → M-H02
  3. Ширина 390: сумка → прилавок → товари згори вниз, усе натискається → M-H03
  4. Довгі назви («Плащ матадора…») — 2 рядки → M-H04

Етап 10. Окремо

  1. Інший Герой → інший набір → M-B03
  2. Наступного дня після 00:00: новий набір M-B04, «Викуп» порожній M-E04, смітник порожній M-F08

Етап 11. Прибирання

  1. Console №9 — усе як до тестів (або лише №8)
  2. Адмінка: Шапці школяра повернути 🛒, видалити «ТЕСТ ціна 0» і «ТЕСТ неактивний»
  3. Після кожного кроку — ✅ / ❌ у списку нижче; для ❌ — нотатка. У кінці «📋 Підсумок»
