# 🏰 SchoolKingdoms

**Гейміфікована освітня платформа для дошкільнят і школярів** — українською мовою.
Дитина вчиться через тести, тренажери, ігри, читання та словник, а її герой росте:
характеристики, монети, спорядження, бої на Турнірній арені. Батьки бачать усе з власного кабінету.

> Ukrainian-language gamified learning platform for kids. A build-less static site on its own server (nginx + Node.js API + PostgreSQL); GitHub keeps the code archive.

🌐 **Сайт:** https://school-king.pp.ua

## 👤 Ролі та вхід

Вхід починається з `index.html`: **«Вхід — user»** (батьки) або **«Вхід — Герой»** (дитина).

- **Батьки** — акаунт з email + паролем, реєстрація родини.
- **Герой** — окрема дитяча сесія на синтетичному email (`login@hero.schoolkingdom.app`), логін і пароль створює дорослий.
- **Адміністратор** — батьківський акаунт із прапорцем адміна (`SK.isAdmin()`), бачить кнопку «⚙️ Адмінка».

Сесія — HttpOnly cookie сервера, тримається рік або до кнопки «🚪 Вийти».
Щоб тестувати Героя й батьків одночасно, потрібні різні браузери або вікно інкогніто.

## 🧩 Спільний шар

Підключається сторінками звичайними тегами — жодних імпортів і збірки.

| Файл | Глобал | Призначення |
|------|--------|-------------|
| `firebase-config.js` | `SK` | Уся робота з даними (назва історична — Firebase більше не використовується): вхід, Герої, тести, завдання, книжки, предмети, словник, друзі, звіти |
| `sk-curriculum.js` | `SKCUR` | Єдина карта королівства (ступені → класи → предмети → розділи → тести); `DEFAULT_MAP` як запасний варіант, коли база недоступна. Має `API_VERSION` — сторінки перевіряють його |
| `sk-header.js` | — | Спільна шапка: бренд, навігація з карти, характеристики активного Героя |
| `sk-footer.js` | — | Спільний нижній навбар; вкладки `home · navch · games · arena`; налаштування — атрибутами `data-active`, `data-back`, `data-last` на теґу `<script>` |
| `sk-progress.js` | — | Health / точність із виконаних завдань, запис у базу |
| `sk-items.js` | `SKIT` | Рушій предметів: бонус екземпляра, міцність, ціна, сумарні відсоткові навички; види зброї (`WEAPON_TYPES`) і типи урону (`DMG_TYPES`: колючий, рублячий, тупий, магічний, вогонь, холод, світло, темрява) — поля речі `weaponType` / `dmgType` |
| `sk-arena-rules.js` | `SKARENA` | Правила бою на арені: бойовий профіль із речей (`fighter`), урон кожного удару (`strike`/`attack`: база + зброя − броня, %, крит, влучання, блок), досвід, зони удару → слоти, знос речей. Читають arena.html і адмінка «Арена» → «Механіка» |
| `sk-skills.js` | `SKSKILLS` | Вміння арени (чернетка дизайну): 4 класи, 30 рівнів, стартові набори, опис / формула / підказка для дітей, теми впровадження й відкриті питання. Також 12 універсальних вмінь рівнів 1–3 (`UNIVERSAL`, рядки механіки) і очки вмінь за рівні (`pointsForLevel`). Читає адмінка «Арена» → «🧠 Механіка вмінь» і «📋 План»; у бою ще не діють |
| `sk-book.js` + `sk-book.css` | `SKBOOK` | Книга вмінь і панель вмінь у вікні Інвентарю арени: вивчення за очки, панель активних вмінь (тап / подвійний тап / перетягування), вибір класу на 3 рівні. Змінює стан лише сервер (`SK.learnSkill` / `setSkillBar` / `chooseClass` → `server/app/src/skills.js`) |
| `sk-avatar.js` | `SKAVA` | Аватари: емодзі, вбудовані герої, локальне фото; модалка вибору |
| `sk-admin.js` + `sk-admin.css` | `SKADMIN` | Спільний шар адмін-сторінок: гейт доступу, шапка, хелпери |
| `sk-report.js` | — | Плаваюча 🐞-кнопка «Повідомити про помилку» |
| `sk-finish.js` | — | Зарахування HTML-сторінки як пройденого запису (`?skdone=t:<testId>`) |
| `sk-zadachi.js` | `ZAD` | Генератор текстових задач (із відмінками) для ігор «Задачі» |
| `sk-readtext.js` | `SKREAD` | Тексти для «Читаю вголос»: вбудований вірш і розбір тексту на строфи/сторінки (тренажер і `admin-chytannia.html`) |
| `sk-styles.css` | — | Спільні стилі: фон, плитки, шапка, футер, адмінка |
| `sk-game.css`, `sk-game-chalk.css` | — | Стилі ігор |

> `firebase-config.js` — ES-модуль, тому `window.SK` зʼявляється **після** `DOMContentLoaded`.
> Не звертайтеся до `SK` одразу: чекайте через `SK.onUser()` або `SKADMIN.whenReady()`.

## 🔥 Дані

Дані лежать на власному сервері в PostgreSQL зі структурою колекцій і документів, як була у Firestore (див. [`server/README.md`](server/README.md)). `sk-fb.js` повторює потрібні функції Firebase SDK. Старий проєкт Firebase — **`schoolkingdom-d46bc`**.

| Колекція | Що зберігає |
|----------|-------------|
| `users` | Батьківські акаунти, родина, прапорець адміна |
| `heroes` | Героїв: характеристики, клас, аватар, монети, інвентар, завдання |
| `heroCards` | Публічні картки Героїв (для друзів і дерева роду) |
| `tests` | Тести й записи навчання (html-сторінки теж тут) |
| `curriculum` | `curriculum/map` — карта королівства; `curriculum/games` — сітка ігор |
| `books` | Бібліотека |
| `items` | Каталог предметів (IT-XXX) |
| `vocab`, `vocabDecks` | Слова й набори словника English |
| `readTexts` | Вірші й тексти для тренажера «Читаю вголос» (`admin-chytannia.html`) |
| `friendships`, `inviteCodes` | Друзі: запрошення з подвійним підтвердженням |
| `reports` | Повідомлення про помилки |
| `meta` | Службові документи |
| `arenaPlan` | План арени: статус, коментар і змінені тексти вмінь, тем і питань; `mech.*` — рядки «Механіки вмінь» (лише адмін) |

Локально в `localStorage` живе те, що не варто гнати в базу: голос озвучки, проходження
(`sk_testpass_<id>`, `sk_dbtest_<id>`, `sk_test100_<id>`), прогрес арени (`sk_arena_*`),
локальне фото аватара (`sk_hero_avatar`).

## 💻 Локальний запуск

Збірки немає — досить будь-якого статичного сервера:

```bash
git clone https://github.com/natalikazichuk/schoolkingdoms.git
cd schoolkingdoms

python3 -m http.server 8000     # або: npx serve .
```

Відкрити `http://localhost:8000`.

> ⚠️ Відкрити файл через `file://` недостатньо: ES-модулі потребують `http(s)`. Вхід і дані працюють лише разом з API (`server/`), тобто на сервері.

## 🚀 Деплой

Сайт працює на власній VM: **https://school-king.pp.ua**. Сервер раз на 2 хвилини
перевіряє гілку `main` на GitHub і сам оновлюється — будь-який мердж у `main` одразу на проді.
GitHub Pages більше не використовується: старі адреси `*.github.io` переводять на новий домен.
Як влаштований сервер, резервні копії й команди — у [`server/README.md`](server/README.md).

### Публічне демо для портфоліо

Цей репозиторій — **приватний**. Назовні відкрита лише демо-версія (1 клас, без бази й входу)
та відео-презентація — в окремому публічному репозиторії
[`natalikazichuk/schoolkingdoms-demo`](https://github.com/natalikazichuk/schoolkingdoms-demo)
на GitHub Pages: https://natalikazichuk.github.io/schoolkingdoms-demo/

```bash
bash tools/publish-demo.sh   # збирає dist-demo/ і пушить у schoolkingdoms-demo (main)
```

Детальніше про склад демо — у [`demo/README.md`](demo/README.md).

Правила доступу — `server/app/src/rules.js` (перенесені з `firestore.rules`).

## 🧷 Домовленості розробки

- **Мова:** інтерфейс і контент — українською; код, імена файлів і змінних — англійською (транслітом).
- **Без дублювання:** спільне живе у `sk-*` файлах. Скопійований у сторінку шматок шапки, футера чи плиток рано чи пізно розійдеться з оригіналом — саме так уже ламалися розміри плиток.
- **Самодостатність сторінки:** кожна сторінка — цілісний файл-заміна; спільні контракти (`sk-curriculum.js`, `test.html`, `sk-styles.css`) без потреби не чіпаємо.
- **Нова сторінка** підключає спільний хедер і футер і має робочу кнопку «Назад».
- **Перевірка перед комітом:** `npm install` (один раз), далі `npm run check` — усе те саме, що робить CI:
  - `npm run audit` — синтаксис JS (і інлайн-скриптів), баланс дужок CSS, розбіжні `?v=N`;
  - `npm run test:server` — тести API;
  - `npm run smoke` / `npm run smoke:demo` — усі сторінки й демо в Chromium.
- **CI** (`.github/workflows/ci.yml`) запускає ці перевірки на кожен PR. `main` одразу йде на прод — мержимо лише зелене.
- **`SKCUR.API_VERSION`** інкрементуємо щоразу, коли міняється експорт `sk-curriculum.js`.
- **Версія кеша:** після правки спільного файлу — `npm run bump -- sk-items.js`: підніме `?v=N` в усіх підключеннях (і версію офлайн-кешу в `sw.js`, якщо файл там є).

## 🖼 Медіа: картинки й озвучка

- **Фони плиток** — `img/nav/`: 16:10, 1200×750 px, WebP, до 150 КБ. Імена й запасні варіанти описані в [`img/nav/README.md`](img/nav/README.md).
- **Решта зображень** — `img/` за домовленим іменуванням (`abc_<letter>.webp`, `colors_<n>.jpg`, …).
- **Озвучка** — `audio/` (`tvaryna_<slug>.mp3`); Learn ABC! — `audio/abc/abc_<letter>.mp3` (генерує `gen_abc.py`).
- **Phonics (англійська)** — `audio/phonics/`: `sounds/phon_s_<графема>.mp3` (звуки), `words/phon_<слово>.mp3` (слова), `letters/phon_n_<літера>.mp3` (назви літер), `male/` (звуки чоловічим голосом, про запас).
- Якщо файлу немає, код не падає: показує запасну картинку за темою або емодзі-чернетку.
