# Картинки для плиток (img/nav/)

Плитки на `navchannia.html`, `doshkillya.html` і `tests.html` показують фон-картинку,
затемнення, назву, підпис і смужку прогресу. Якщо файлу немає — плитка
підставляє спільну картинку за темою, а якщо і її немає — лишається кольорова плашка.

## Який файл як називається

| Файл | Де видно |
|---|---|
| `doshkillyatko.webp`, `molodsha.webp`, `starsha.webp` | ступені на «Навчанні» + запасний фон класів |
| `klas-1.webp` … `klas-11.webp` | окрема картинка для кожного класу (без неї — `molodsha/starsha`) |
| `dis-tsyfry.webp`, `dis-bukvy.webp`, `dis-english.webp`, `dis-svit.webp` | дошкільні напрями + запасний фон предметів за темою |
| `subj-math.webp`, `subj-ukr.webp`, `subj-eng.webp`, `subj-yads.webp`, `subj-fun.webp` | окрема картинка для предмета (`subj-<id предмета>.webp`) |

`<id предмета>` видно в адмінці → «🗺 Структура». Для доданого в адмінці предмета
id згенерований (`s` + час) — тоді простіше покластися на запасну картинку за назвою.

## Розмір і вага

* Пропорції — **16:10** (плитка має `aspect-ratio:16/10`; на телефоні обрізається по центру).
* Розмір — **1200 × 750 px** (мінімум 900 × 563, більше за 1600 px не треба).
* Формат — **WebP**, якість 78–82.
* Вага — **до 150 КБ** на файл, добре коли 60–120 КБ.
* Важливе (герой, головний обʼєкт) тримати праворуч або по центру:
  зліва лягає емодзі-іконка, знизу — назва й смужка прогресу.
* Картинка має бути світлішою зверху й спокійною знизу — там текст на затемненні.
