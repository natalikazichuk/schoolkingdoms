# Картинки для плиток (img/nav/)

Плитки на `navchannia.html`, `doshkillya.html` і `tests.html` показують фон-картинку,
затемнення, назву, підпис і смужку прогресу. Якщо файлу немає — плитка
підставляє спільну картинку за темою, а якщо і її немає — лишається кольорова плашка.

## Який файл як називається

| Файл | Де видно |
|---|---|
| `doshkillyatko.webp`, `molodsha.webp`, `starsha.webp` | ступені на «Навчанні» + запасний фон класів |
| `klas-1.webp` … `klas-11.webp` | окрема картинка для кожного класу (без неї — `molodsha/starsha`) |
| `dis-tsyfry.webp`, `dis-bukvy.webp`, `dis-english.webp`, `dis-svit.webp` | дошкільні напрями + запасний фон предметів за темою |
| `tema-informatyka.webp`, `tema-istoriya.webp`, `tema-dozvillya.webp` | запасний фон предметів «Інформатика», «Історія», «Дозвілля» за назвою (будь-який клас) |
| `subj-math.webp`, `subj-ukr.webp`, `subj-eng.webp`, `subj-yads.webp`, `subj-fun.webp` | окрема картинка для предмета (`subj-<id предмета>.webp`) |

`<id предмета>` видно в адмінці → «🗺 Структура». Для доданого в адмінці предмета
id згенерований (`s` + час) — тоді простіше покластися на запасну картинку за назвою.

## Розмір і вага

* Пропорції — **16:10** (на телефоні плитка стає 16:9 і обрізається по центру,
  тож по 6% зверху та знизу можуть зникнути).
* Розмір — **1200 × 750 px** (мінімум 900 × 563, більше за 1600 px не треба).
* Формат — **WebP**, якість 78–82.
* Вага — **до 150 КБ** на файл, добре коли 60–120 КБ.
* Важливе (герой, головний обʼєкт) тримати праворуч або по центру:
  зліва лягає емодзі-іконка, знизу — назва й смужка прогресу.
* Картинка має бути світлішою зверху й спокійною знизу — там текст на затемненні.
* Назву не «вмальовувати» в картинку: плитка сама пише назву й підпис.

Стилі плитки — спільні, у `sk-styles.css` (`.lvgrid/.nv-grid` + `.lv*`).
У сторінкові `<style>` їх не копіювати — саме через копії розміри розʼїжджались.

## Обкладинки тем (img/tr/)

Картка теми на `tests.html` і `navchannia.html` бере обкладинку так:
поле «Обкладинка» в адмінці → `img/tr/<назва-сторінки>.webp` (для тренажерів-посилань)
→ картинка за назвою теми (`sk-covers.js`) → емодзі.
Та сама обкладинка показується над назвою на стартовому екрані тесту (`test.html`).
Обкладинки тем — квадрат 600 × 600, без тексту (назву пише сама картка).
Інформатика 1 кл.: `inf1-*.webp` (запасні варіанти — з хвостиком `-2`) і `komputer.webp` («Комп'ютерний детектив»).
Решта тем Інформатики 1 кл. (без власної картинки й без збігу за назвою) — `inf1-informatyka.webp` (`SKCovers.bySubject`).
Українська мова: `ukr-*.webp` (букви і звуки, порядок букв/літер, голосні/приголосні, дзвінкі/глухі, тверді/м'які, назви/дії/ознаки предметів, слово, велика і мала літера, знайди літеру письмову, списування, вчимось писати, мовний квест, текст, речення).
ЯДС: `yads-*.webp` (державні символи, Батьківщина, місто, школа, школярик, родина, дружба, безпека вдома / на вулиці, ПДР, пожежна безпека, вода-повітря-ґрунт, досліди, пори року, рослини, тварини, екологія, погода, корисна їжа, здоровий спосіб життя, професії, досягнення, гроші; «Як досягти результату» — `yads-zirka-shchyt.webp`; `yads-pravyla-plan.webp` ставиться вручну в адмінці).
Математика та загальні: `mat-*.webp` (канікули, досягнення — для всіх, крім ЯДС, попереднє і наступне число, лабіринт, пазли).
