## 4. Технічна основа (Етап 0 — перед новими рівнями)

1. **Шаблон рівня `nav-level.js`** поверх наявного `nav-common.js`. Новий рівень — це маленький `.html` з даними:
   - коротка історія (1–2 речення) → дія (вибір / введення / кнопки) → перевірка;
   - при помилці — пояснювальна підказка, спроба ще раз (рівень не блокується);
   - після правильної відповіді — 🔄 переворот, нове правило, друга задача;
   - «💡 Чому так?» з розв'язанням по кроках;
   - фініш — як у наявних іграх (`NAV.finish`): екран перемоги, нагорода з адмінки, «Вирушай далі! ›».
   Окремий файл на рівень лишаємо, бо адмінка шукає нагороду за назвою файлу.
2. **Карти розділів.** 30 пунктів на одну карту не помістяться, тому:
   - `index.html` → **хаб із 6 розділів**: розділ відкривається, коли пройдено попередній;
   - **карта розділу** — шаблон теперішньої карти «Дивне місто»: фон, стежка, 5 пунктів (у Розділі II — 7: ще Площа і Двірник);
   - Розділ I бере вже готовий фон `img/map-bg.webp`.
3. **Генератори з перевіркою** для загадок «правда/брехня» (2, 6, 14, 21): перебором переконатися, що розв'язок один **і** у звичайному, **і** в 🔄 режимі.
4. **Автотести** Playwright: кожен рівень відкривається, проходиться, переворот працює, «Вирушай далі» веде на наступний.
5. **Нагороди** — за встановленими правилами сайту: адмінка + `SKPRIZE.claim`, у коді рівнів нічого нового.
