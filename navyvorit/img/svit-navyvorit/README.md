# 🌳 Дивне дерево (`svit-navyvorit.html`) — картинки для редизайну

Макет — `_maket.webp` у цій папці. Склади сюди файли **саме з такими назвами** — і я підключу їх у гру.

## Загальні вимоги

- Формат **`.webp`** (як інші картинки сайту в `img/tr/`). Якщо зручніше — `.png`, я сконвертую.
- Стиль — як на макеті: м'який 3D-мультяшний, яскравий, без тексту на картинках.
- **Прозорий фон** — для всіх предметів (позначено 🫥). Без тіні «на підлозі» — тінь додам у коді.
- Кожен предмет — **окремим файлом**, бо в грі вони рухаються: дерево перевертається, яблуко злітає вгору, кошик перевертається догори дном.

## Не треба малювати

- **Заголовок «Спіймай яблуко!»**, «Світ навиворіт · Логіка», тексти плашок і кнопок — зроблю шрифтом у коді (жовтий об'ємний напис, як на макеті), щоб їх можна було змінювати й перекладати.
- **Сонечко-жучок 🐞 з «?»** угорі праворуч — це загальна кнопка «Повідомити про помилку» на всіх сторінках сайту. Якщо хочеш таку намальовану, це окреме завдання для всього сайту.
- **Нижнє меню** (Головна / Навчання / Ігри / Арена / Назад) — спільне для сайту, його не чіпаю.
- Перевернуте дерево, перевернутий кошик, фіолетова тема «Навиворіт» — роблю в коді з тих самих картинок.

## Порада для генерації

Для `tree.webp` і `scene-bg.webp` важливо, щоб **лінія трави збігалася**: якщо генеруєш окремо — постав дерево так, щоб межа «стовбур → коріння» була на тій самій висоті, що й трава на фоні (≈62–65 % висоти). Якщо не вийде — нічого, підлаштую в коді.
