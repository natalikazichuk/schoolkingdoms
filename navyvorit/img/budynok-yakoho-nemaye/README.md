# 🏚️ Будинок, якого немає (`budynok-yakoho-nemaye.html`) — картинки для редизайну

Макет — `_maket.webp` у цій папці.

**Стан:** усі 8 картинок уже в грі ✅ (друга версія: сцена з кам'яною доріжкою, кругла ділянка). Номер на табличці пише код — і на звичайному, і на відчиненому будинку. `start-hero.webp` — діти, принцеса і собака-робот біля замку (замість будинку з годинником).

## Загальні вимоги
- Формат `.webp` або `.png` (сконвертую). Стиль — як на макеті: м'який 3D, яскравий.
- **Без тексту й цифр**: номер на табличці, годинник «час іде вперед», журнал, кнопки й підказки — це код.
- 🫥 — **прозорий фон**, без тіні на землі (тінь додам у коді).
- Окремої «навиворіт»-версії не треба: фіолетовий тон роблю в коді.
