# 🚌 Автобус №0 (`avtobus-0.html`) — картинки для редизайну

Склади сюди файли **саме з такими назвами** — і я підключу їх у гру. Без якогось файлу гра працює як зараз (емодзі).

## Загальні вимоги
- Формат `.webp` або `.png` (сконвертую). Стиль — як у «Дивному дереві»: м'який 3D-мультяшний, яскравий.
- **Без тексту й цифр** на картинках — номери зупинок, «Автобус №0», підписи роблю в коді.
- 🫥 — **прозорий фон**, без тіні на землі (тінь додам у коді).
