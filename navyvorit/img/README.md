## `map-bg.webp` — фон карти «Дивне місто»

Зараз на карті стоїть квадратний `bg.webp`, розтягнутий на високу карту, — тому видно лише середню смужку (стрілки й листя крупним планом). Для карти потрібна **окрема висока картинка**.

### Розмір і формат
- **Вертикальна, 9 : 24** — напр. **1080 × 2880** (або 1200 × 3200). Формат `.webp` або `.png`.
- Суцільний фон (без прозорості). **Без тексту, без персонажів і без кружечків-пунктів** — їх, номери й підписи малюю в коді.
- **Дорогу/стежку не малювати** — пунктирну стежку малюю в коді (так її легко змінювати). Можна лише ледь помітні вулички.
- Стиль — як у `bg.webp` / «Дивному дереві»: м'який 3D-мультяшний, яскравий.

### Зони — знизу вгору (відсотки — від **верху** картинки)

День на карті поступово переходить у ніч. Переходи між зонами — плавні.

| Від верху | Зона | Що намалювати |
|---|---|---|
| **82–100 %** | 🏡 **Передмістя · ранок** | Луг, трава, квіти, дерев'яний паркан, кілька дерев. Унизу по центру — **місце для воріт** (вільна галявинка, можна арку/ворота міста). Ліворуч унизу — вільне місце, де стоїть пункт «Дивне дерево». Ранкове світле небо не потрібне — це вигляд «згори-збоку» на землю |
| **77–82 %** | 🌊 **Річка з мостом** | Річка через усю ширину; **дерев'яний міст по центру** (≈ 43–57 % ширини) |
| **42–77 %** | 🏙️ **Дивне місто · день** | Казкове місто вдень: бруківка, будиночки з черепичними дахами, ліхтарі, клумби. Ліворуч угорі зони — годинникова вежа (там пункт «Годинникова вежа»), посередині — площа з фонтаном/статуями |
| **24–42 %** | 🌆 **Житлова вулиця · вечір** | Будиночки з вікнами, що світяться, захід сонця (помаранчево-рожеве небо між дахами), перші ліхтарі |
| **0–24 %** | 🌃 **Ніч** | Нічне небо з місяцем і зорями, будинки з освітленими вікнами, ліхтарі. Нагорі — музичний будинок (вікна різних кольорів 🔴🔵🟢🟡 — буде дуже доречно) |

### Де стоять пункти (щоб там був спокійний фон)

Кружечки пунктів ≈ 14 % ширини. У цих місцях бажано **не малювати дрібних яскравих деталей** (людей, вивісок) — щоб пункти й підписи читалися. Координати — центр пункту, `x` від лівого краю, `y` від верху:

| Пункт | x | y |
|---|---|---|
| 🎟️ Ворота | 50 % | 95 % |
| 1 🌳 Дивне дерево | 22 % | 90 % |
| 2 🚌 Автобус №0 | 76 % | 86 % |
| 3 🕰️ Годинникова вежа | 26 % | 72 % |
| 4 🗿 Площа з пам'ятниками | 72 % | 66 % |
| 5 🧹 Двірник | 26 % | 60 % |
| 6 🏪 Дивний магазин | 74 % | 53 % |
| 7 🏦 Банк | 28 % | 46 % |
| 8 🚪 Будинок із дверима | 72 % | 38 % |
| 9 🏚️ Будинок, якого немає | 28 % | 30 % |
| 10 🔦 Ліхтарі | 72 % | 20 % |
| 11 🎵 Музичний будинок | 38 % | 10 % |

Під кожним пунктом — підпис (≈ 4 % висоти нижче центру).

### 🔄 Переворот
Під час «Перевороту» карта обертається догори дриґом (верх стає низом) — окрему картинку для цього малювати **не обов'язково**.
За бажанням можна дати ще `map-bg-flip.webp` (того самого розміру): те саме місто, але **день і ніч навпаки** — передмістя вночі, а нагорі ясний день. Тоді під час перевороту я підміню фон.
