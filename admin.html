🔀 Приналежність

Тут зібрано всі тести й випробування. Для кожного можна змінити тип (тест ↔ випробування), предмет і клас — зокрема дошкільнят. Зміни зберігаються одразу.
«Тест → Випробування» створює посилання на test.html?id=… і ховає тест зі сторінки «Тести». Зворотне повертає тест назад.

🎮 Випробування

Випробування — це посилання на окрему сторінку або відео, яке зʼявляється під предметом на сторінці «Тести». Обери предмет, дай назву й встав посилання — внутрішню сторінку (напр. english-reading.html) або зовнішнє посилання/відео (https://…).
Ступінь і клас — необовʼязкові фільтри: залиш «усі ступені»/«усі класи», щоб випробування показувалось скрізь із цим предметом. Обери клас (1–4), щоб зʼявлялось тільки в тому класі.
Нагороди — до 4 речей. У кожному слоті: ID предмета з інвентаря (напр. IT-001), шанс випадіння 0–100% (крок 10%) і, за бажанням, монетки. Слот спрацьовує за своїм шансом; дитині нагороди не показуються — це таємниця. Картинка — одна на все випробування: поклади файл img/tr/<назва-сторінки>.webp з тією самою назвою, що й сторінка в посиланні (напр. посилання vchymo-tsyfry.html → файл img/tr/vchymo-tsyfry.webp). Вона показується і на плашці, і на першій сторінці випробування. Немає файлу — показується емодзі-іконка. Порожні рядки не зберігаються.

🕹 Ігри

Ігри показуються на сторінці «Ігри» (igry.html), згруповані за полем Група. Групу пишеш вільно (можна вибрати з підказок) — напр. «Математика», «Логіка та памʼять», «Аркади». Ігри з однаковою групою стають однією згортуваною секцією; порожня група потрапляє в «Інші».
Тут вирішуєш сама, що́ гра, а що́ випробування: посилання-випробування під предметами — у вкладці «🎮 Випробування», а ігротека — тут.
Порожні рядки не зберігаються.

Імпорт тестів (JSON)

Встав один тест або масив тестів. Звичайний: { title, subject, grade, stat, …, questions:[{ q, options:[…], correct }] }
Рівні: { title, …, format:"levels", levels:[{ level, name, questions:[…] }] }
Ілюстрація (необов'язково, у питанні): "visual": { "type":"number-line", "from":1, "to":10, "highlight":[4] } або { "type":"number-blocks", "value":6, "groups":[2,4] }
