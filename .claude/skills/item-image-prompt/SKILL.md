# Промт для картинки речі

Усі речі магазину (`img/items/<код>.webp`) мають один стиль: напівреалістичний 3D, м'яке світло,
**прозоре тло** і легка напівпрозора тінь під річчю. Щоб стиль не розходився, промт завжди
збирається з одного шаблону.

## Звідки брати шаблон

Джерело правди — `SKIT.imagePrompt({name, category, weaponType, desc, tier})` у `sk-items.js`.
Той самий промт видає адмінка «Предмети» (`admin-items.html` → панель **🎨 Промт для картинки речі**,
а в редакторі речі — кнопка «🎨 Промт для картинки цієї речі»). Не переписуй шаблон з пам'яті —
згенеруй його цією функцією, наприклад:

```bash
node -e "const vm=require('vm'),fs=require('fs');const w={};w.window=w;vm.runInNewContext(fs.readFileSync('sk-items.js','utf8'),w);
console.log(w.SKIT.imagePrompt({name:'Мисливський лук',category:'Зброя',weaponType:'bow',tier:'uncommon',
desc:\"a sturdy hunter's recurve bow of dark wood, leather-wrapped grip\"}))"
```

- `category` — як у каталозі: `Зброя`, `Щити`, `Шоломи`, `Обладунки`, `Рукавиці`, `Наручі`, `Пояси`,
  `Штани`, `Взуття`, `Кільце`, `Амулет`, `Зелья`, `Свиток`.
- `weaponType` (лише для зброї) — `SKIT.WEAPON_TYPES`: sword, dagger, axe, mace, flail, spear, whip,
  staff, wand, knuckles, bow, exotic.
- `tier` — `common` / `uncommon` / `rare` / `epic` / `legendary` (чим рідкісніша, тим багатші матеріали;
  світіння — лише з epic).
- `desc` — як річ виглядає, **англійською** (матеріал, колір, деталі). Порожньо — візьметься назва.

## Як відповідати

1. Видай готовий промт (блоком коду, щоб легко скопіювати) — для кожної речі окремо.
2. Нагадай коротко: зберегти PNG із прозорим тлом; надіслати картинку — її переганяють у
   `img/items/<код>.webp` 512×512 (RGBA), як інші речі.
3. Якщо просять кілька речей одного виду (напр. 5 луків) — розклади їх від простої до
   легендарної, у кожної свій `desc` і `tier`.

Змінити сам стиль (світло, тінь, ракурс) — лише в `imagePrompt` у `sk-items.js`, тоді адмінка
й ця навичка зміняться разом.
