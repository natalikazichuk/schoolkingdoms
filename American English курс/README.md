- [`American English для молодшої школи.pdf`](American%20English%20для%20молодшої%20школи.pdf) — опис курсу: обкладинка, зміст із закладками, про курс, програма кожного класу й сторінка-опис кожного готового модуля (з номерами сторінок його аркушів).
- [`American English для молодшої школи — аркуші для друку.pdf`](American%20English%20для%20молодшої%20школи%20—%20аркуші%20для%20друку.pdf) — усі аркуші A4 готових модулів; на першій сторінці зміст із номерами сторінок кожного модуля.

## Як доповнювати курс

Обидва файли щоразу збираються заново, тому нічого не треба вставляти вручну.

1. Новий модуль на сайті: додати його в `MODS` тренажера класу (для 2 класу — у `2 клас english/tools/build_site_g2.py`, потім запустити скрипт).
2. Аркуші модуля покласти в `N клас english/module-XX-<назва>/worksheets.pdf` (назва папки = поле `pdf` у `MODS`).
3. За потреби поправити опис у [`course.json`](course.json): місяць, години, мовні зразки, пісні; новий клас — новий запис у `grades`.
4. Зібрати обидва файли:

   ```
   python3 "American English курс/build_course.py"
   ```

Модуль потрапляє у файл, коли він є і в тренажері на сайті, і має `worksheets.pdf`; до того він показується в таблиці програми як «у розробці».

Потрібно: `python3` з `pypdf` і `reportlab`, `node` з `playwright` (Chromium), шрифт DejaVu Sans.
